# 사용자 지정 인물·지명 기준

2026-09-11 사용자가 제공한 정보를 번역 기준으로 보존한다. 사건과 분기는 게임 원문을 대조하고, 아래 설명을 게임 대사에 새로 삽입하지 않는다.

## 이름

주역: 라티크스 파렌스, 밀리 킬리트, 로닉스 J. 케니, 이리아 실베스트리.

동료: 돈 마르토, 시우스 워렌, 요슈아 제란드, 피아 멜, 마벨 프로즌, 아슈레이 반벨트, 티니크 알카나, 페리시, 웰치 빈야드, 에리스 제란드.

기타: 마르토스 킬리트, 바담, 라이어스 워렌, 붉은 방패, 루시오, 아스모데우스, 이레나, 지에 리보스, 베이스 제독. 라티의 어머니와 카르나스 함의 의사는 이름을 임의로 만들지 않는다.

자기소개 등의 성명은 위 표기를 사용한다. 화자·파티 표시는 이름만 사용하며, 원문이 애칭으로 부르는 라티는 유지한다. 페리시/펠리시 혼재는 사용자가 먼저 명시한 페리시로 통일한다. 로크/론 혼재는 로크로 통일한다.

## 관계와 문맥

- 마르토스 킬리트는 밀리의 아버지이며 문장술을 가르쳤다. 돈 마르토와 다른 인물이다.
- 라티의 어머니는 남편을 잃고 라티와 살고 있다.
- 라이어스 워렌은 시우스의 친아버지이자 피아의 양아버지이며 아스트랄 기사단장이다. 아슈레이와 마왕 토벌의 전우다.
- 요슈아와 에리스는 남매다. 마벨·에리스의 정체와 관련된 대사는 해당 시점의 원문 공개 범위를 유지한다.
- 바담은 호트의 도구상이며 포트미스 무기점의 물건을 가져오는 일을 의뢰한다.
- 루시오는 밀리가 신세를 진 여관 주인의 아들이다.
- 이레나는 지에 리보스에 맞서는 저항 단체의 수장이다.
- 베이스 제독은 로닉스의 상관이다. 카르나스 함의 의사는 돈을 진료한다.
- 아스모데우스는 파겟에서 만들어져 로크로 탈주한 초인류다. 혈액 시료로 만든 병기가 300년 뒤 로크의 사건과 연결된다.
- 레조니아는 지에 리보스의 협박을 받는 세력이다.

## 지명

로크 행성, 크라토스(현대), 크라트(300년 전), 메토쿠스 산.

무아 왕국: 호트, 포트미스.

아스트랄 왕국: 오터님, 타트로이, 아스트랄 성, 트롭, 퍼지 신전.

반 왕국: 엑더트, 이오니스, 반 이 일 성(줄임말 반 성).

실바란트 왕국: 둘스, 실바란트 성, 구 이종족의 유적.

기타: 마계, 파겟 행성, 카르나스 함, 레조니아.

동료 가입 조건은 분기별 원문과 게임 로직을 따른다. 참고문에 기재된 조건을 이유로 이벤트 로직을 바꾸지 않는다.
