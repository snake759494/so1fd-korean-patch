# 구현 및 수정 내역

이 게임은 모든 화면이 하나의 공통 한자 글꼴을 쓰는 구조가 아닙니다. 필드 대사, 메뉴, 공통 메시지, 전투, 이름 입력, 아이템 제목에 서로 다른 글꼴·문자 참조 방식이 있습니다. 따라서 완성형 한글 2,350자를 한 이미지에 넣는 방식 대신, 각 뱅크에서 필요한 한글을 모아 글꼴 칸을 배정하고 문자열 코드를 함께 다시 인코딩했습니다.

## 대사와 메뉴

자체 문자 코드와 압축 패키지를 해독한 뒤, 원문과 위치를 수집하고 번역을 삽입합니다. 공간과 줄 수에 맞춰 줄바꿈을 조정합니다. 색상·강조·가변 이름·아이템 참조 토큰은 일반 텍스트와 분리하여 보존합니다. 노란색 대사가 부자연스러웠던 부분은 제어 토큰을 포함한 전체 문맥으로 재검수했습니다.

마을 집·상점에서 멈추던 문제는 일부 압축 블록의 최초 할당과 연결 배치에 관련되어 있었습니다. 원래 블록 구조와 필요한 배치를 유지하며 번역 데이터를 넣도록 수정하고 해당 건물의 진입·대화·퇴장을 확인했습니다.

아이템 큰 제목은 본문과 별개의 이미지여서 제목 이미지도 재작성합니다. 뒤따르는 아이콘 압축 자료는 보존합니다. 숫자와 ASCII만으로 충분한 제목은 유지합니다.

## 인물 이름

기본 이름은 14명을 한글로 설정합니다. 동적 이름은 24개의 한글 음절을 별도 코드에 대응시키는 방식이며 필드·메뉴·공통표마다 대응 글꼴 위치가 다릅니다. 실행 파일의 이름 변환과 전투의 영문 대문자 별칭 처리를 수정하고 여러 이름용 글꼴을 함께 갱신했습니다.

Review 10에서는 레벨업 메시지의 동적 이름이 241~264번 글꼴 칸을 참조하지만 해당 칸에 원래 일본어가 남아 있던 문제를 고쳤습니다. 공통표 member 10·1709·3320의 같은 위치에 한글 이름 글꼴을 예약하고 기존 문자열 참조를 옮겼습니다. 기존 문구의 글자 모양·제어 코드가 유지되는지 비교했습니다. Review 09 대비 이 세 공통표가 변경되었고 BOOT/EBOOT는 동일합니다.

## 검증 구분

정적 검사는 변경 범위, 압축·필드 구조, 문자 참조, 제어 코드와 글꼴 픽셀을 다룹니다. xdelta 적용 결과를 완성 ISO와 바이트 단위로 비교했습니다. 런타임 검사는 PPSSPP에서 특정 장면이 실제로 표시되고 진행되는지 확인합니다. 전체 동료 조합과 엔딩 완주는 별도 범위이며 완료하지 않았습니다.

공개 검증 JSON은 당시 시험 기록입니다. 거기에 기재된 로컬 이미지·스테이트·바이너리는 저장소에 포함하지 않습니다. 특히 Review 10의 스테이트 기반 시험 조건은 README에 명시되어 있으므로, 이 결과를 전체 게임 새 게임 완주 결과로 해석하지 마세요.
